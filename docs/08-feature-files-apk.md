# Фичи: файловый менеджер и менеджер APK

## Файловый менеджер

### Корни

| Корень | Путь | Права |
|--------|------|-------|
| Общее хранилище | `/sdcard` | read/write (shell) |
| Staging | `/data/local/tmp` | read/write, временные файлы |
| Система | `/system`, `/product` | read-only (частично) |

Пользовательская директория по умолчанию: `/sdcard/QuestWebManager/`
(создаётся при первой загрузке). Навигация: хлебные крошки, «..» вверх до `/`.

### Список файлов

- Команда: `ls -l <dir>` (toybox). Формат:
  `perms links owner group size date name`.
  - isDir — первая буква `d`; symlink `l` — показываем, не рекурсируем.
  - date: toybox `Mon DD HH:MM` или `Mon DD YYYY` — loose-regex, при сбое —
    пустая ячейка.
  - name: последнее поле (дата стоит фиксированно, имя — всё после неё).
- **К проверке**: точный формат `ls -l` на Quest (M2). Если парсинг
  неустойчив — fallback `stat` на запись (медленно, только текущий каталог).
- Сортировка: имя/размер/дата, asc/desc (клиентская).
- Скрытые файлы (`.*`) — toggle, по умолчанию включены.

### Операции

| Операция | Команда/сервис | Примечание |
|----------|----------------|------------|
| Создать папку | `mkdir -p` | диалог имени |
| Переименовать | `mv` | диалог |
| Удалить | `rm -rf` | подтверждение (для каталога — жёсткое) |
| Загрузить | `Sync.push` | очередь, прогресс, overwrite/skip/rename |
| Скачать | `Sync.pull` | файл → download; каталог → zip (fflate) |
| Копировать | v2 | `cp -r` |

### Загрузка (детали)

- Очередь (input file multiple / drag&drop).
- Для каждого файла:
  1. Санитизация имени: `/\:*?"<>|` → `_`, ≤ 200 символов, непустое.
  2. Коллизия (файл уже есть) → выбор пользователя: **overwrite**
     (по умолчанию) / skip / rename (`name (1).ext`).
  3. `push` с прогрессом (sent/total, MB/s).
  4. FAIL → помечаем файл, очередь продолжается.
- Отмена: на файл и на очередь целиком (AbortController).
- После очереди: сводка (N ok, M failed).

### Скачивание (детали)

- Один файл: `pull` → Blob → `<a download>`.
- Каталог: pull каждого файла (лимит на число записей — предупреждение)
  → zip в памяти (fflate) → download `<name>.zip`.
- Прогресс: indeterminate + счётчик файлов (v1).

### Краевые случаи

- Кириллические имена — ок (UTF-8); проверить кодировку `ls` на шлеме.
- Нет места (FAIL ENOS) — понятное сообщение + актуальная `df`.
- Файл изменился во время upload — в v1 без checksum-верификации
  (IDST — v2).

## Менеджер APK

### Список

- `pm list packages -f` → таблица: pkg, тип (system/third-party), путь;
  версии лениво.
- Версии лениво (раскрытие строки): `dumpsys package <pkg>` →
  `versionName`, `versionCode`, `lastUpdateTime`.
- Фильтр: поиск по тексту, toggle «только third-party» (по умолчанию вкл).
  Счётчик приложений — бейдж.

### Установка

- Источник: файл из браузера `.apk` (`.xapk`/`.apks` — отклоняем с
  подсказкой в v1).
- Флоу: валидация (расширение, размер ≤ 2 GB) → push (прогресс «загрузка»)
  → `pm install -r -d` (120 s) → парсинг:
  - `Success` → ок.
  - `Failure [INSTALL_FAILED_…]` → код + человек-подсказка. Таблица частых
    кодов: `VERSION_DOWNGRADE`, `UPDATE_INCOMPATIBLE`,
    `INSUFFICIENT_STORAGE`, `PARSE_FAILED_NO_CERTIFICATES`.
- `rm` в finally. «Обновить» = `-r`; «разрешить даунгрейд» = `-d`
  (toggle, по умолчанию вкл).
- После успешной установки — кнопка «Запустить».

### Прочие операции

- Удалить third-party: `pm uninstall <pkg>`, с подтверждением.
- Удалить system: `pm uninstall --user 0 <pkg>` — кнопка «Скрыть»,
  предупреждение (вернётся после factory reset).
- Запуск: `monkey -p <pkg> -c android.intent.category.LAUNCHER 1`.
- Force-stop: `am force-stop <pkg>`.
- Права (`pm grant/deny`) — v2.
