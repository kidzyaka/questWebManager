# UX и флоу

## Общие

- Только десктоп, мин. ширина 1024px (меньше — подсказка «откройте на
  компьютере»).
- Тёмная тема (основная), акцентный цвет, моноширинный шрифт для логов
  и путей.
- Русский (v1); строки — в `ui/strings.ts`.
- Сети ноль (шрифты не с CDN — локальные).

## Макет

```
┌──────────────────────────────────────────────────────────────┐
│ [logo] Quest Web Manager        [Quest 3 · 87% · 42.1°C]    │
├──────────────────────────────────────────────────────────────┤
│ Device | Files | Apps | Settings | Power | Backup | Log      │
├──────────────────────────────────────────────────────────────┤
│                      (содержимое вкладки)                    │
└──────────────────────────────────────────────────────────────┘
```

- Топбар: чип устройства (модель, батарея, температура), цвет статуса:
  зелёный (подключено) / жёлтый (подключение) / красный (потеряно) /
  серый (нет подключения).
- Вкладки: disabled без подключения (кроме «Log» и «Device» — они
  показывают статус).

## Подключение: состояния

```
                    клик пользователя
  IDLE ──────────────────────────> REQUESTING
   ^                                  │ промпт браузера + requestDevice
   │                                  v
  CLOSED <────────────────────── OPENING (usb open/claim)
   ^                                  v
   │                            HANDSHAKE (CNXN)
   │                       fail         ok
   │                        v            v
   │                     ERROR         READY
   │                                        v
   └── (действие) ──── RECONNECT_WAIT <── (отключение/reboot)
```

- **IDLE**: большая кнопка «Подключить шлем» + чек-лист: «1. ADB на
  шлеме (Настройки → Для разработчиков → ADB), 2. кабель, 3. нажать
  кнопку».
- **REQUESTING**: спиннер, «браузер просит разрешение — выберите шлем в
  окне».
- **OPENING/HANDSHAKE**: спиннер со стадией (USB / ADB handshake).
- **ERROR**: причина + подсказки (драйвер, кабель, ADB, браузер) +
  «Повторить».
- **RECONNECT_WAIT**: жёлтый баннер: «Шлем отключился. Подключите и
  нажмите здесь» — кнопка (requestDevice, без промпта если разрешение
  запомнено).
- **READY**: чип зелёный, вкладки активны.

## Прогресс и очереди

- Долгая операция (upload, бэкап, установка) — карточка: имя, прогресс-бар
  (байты + %), скорость (MB/s), ETA, «Отменить».
- Очередь: список карточек, общий прогресс сверху.
- После завершения: зелёная галка / красная причина (клик → вкладка Log).

## Ошибки

- На операцию: тост (4 c) с причиной.
- Фатальная транспортная: фулскрин-состояние (RECONNECT_WAIT / ERROR).
- Вкладка «Log», две секции:
  - **События приложения** (EventBus: usb/adb/services; уровни
    info/warn/error), фильтр по уровню.
  - **Устройство (logcat)** — стриминговый tail (старт/стоп), фильтр по
    тексту, пауза.
- Автоскролл (toggle), лимит 5000 строк, «Копировать» / «Скачать .log».

## Вкладка Device

- Карточки: модель, сериал, Android, build, ADB state; батарея (бар,
  plugged, температура, health); хранилище (занято/всего, бар); uptime.
- «Обновить» + авто каждые 30 c.
- Быстрые действия: перезагрузка, выключение (с подтверждением).

## Безопасность в UI

- Первый-визит модалка (один раз, localStorage): «У этого сайта полный
  доступ к подключённому шлему (shell). Используйте только если доверяете
  источнику страницы». — «Понятно» / «Закрыть».
- Футер: «локальное приложение · данные не покидают компьютер».

## Детали

- Кнопки ≥ 32px, видимый focus.
- Tooltip `title` с точной командой (прозрачность).
- Кнопки копирования путей.
