# Quest Web Manager — Обзор

## Что это за проект

Веб-приложение для управления шлемами Meta Quest (Quest 2 / 3 / 3S / Pro)
из десктопного браузера. Связь со шлемом — по **USB-кабелю** через API
**WebUSB** и протокол **ADB** (тот же, что использует утилита `adb`).

Без бэкенда, без установки, без драйверов (браузер сам работает с USB-устройством):
открыл страницу → подключил шлем → управляешь.

## Цели (v1)

1. **Файловый менеджер** — просмотр файловой системы шлема, загрузка файлов,
   скачивание, удаление, создание папок.
2. **Менеджер APK** — установка APK (sideload), список, удаление, запуск, force-stop.
3. **Настройки** — изменение настроек шлема из веб-панели (всё, что имеет
   ADB/shell-интерфейс) + встроенный инструмент исследования новых ключей.
4. **Питание** — перезагрузка, выключение; статус: батарея, температура, uptime.
5. **Бэкап** — селективный бэкап (APK, /sdcard, настройки) и восстановление.
6. **Логи** — живой logcat устройства + журнал событий приложения.

## Не цели (v1)

- Беспроводное соединение (ADB over Wi-Fi — кандидат на v2, нужен локальный WebSocket-мост).
- Мобильные браузеры и iOS.
- Firefox/Safari (нет WebUSB).
- Полный бэкап с данными приложений (нет root, `adb backup` недоступен).
- Стриминг экрана в 60+ fps (медленный debug-просмотр скриншотов — вне v1).
- Произвольная прошивка (есть «ассистент прошивки» — экспериментальная фича).
- Root, модификация системы.

## Жёсткие ограничения

| # | Ограничение | Следствие |
|---|-------------|-----------|
| 1 | WebUSB — только Chromium (Chrome/Edge) | целевая платформа: десктоп, Chrome/Edge |
| 2 | Обязателен USB-кабель | шлем должен быть подключён кабелем |
| 3 | WebUSB — только secure context | страница должна отдаваться по HTTPS (или localhost в dev) |
| 4 | ADB — пользователь `shell`, не root | часть `/data` недоступна |
| 5 | ADB работает только при включённом шлеме | «включить» шлем из панели невозможно |
| 6 | При перезагрузке устройство пропадает с USB | приложение обязано переживать отключение и переподключение |
| 7 | Закрытие вкладки убивает сессию | предупреждать пользователя при длинных операциях |

## Глоссарий

- **ADB** — Android Debug Bridge, протокол управления Android-устройством.
- **adbd** — ADB-демон на устройстве.
- **WebUSB** — браузерный API (Chromium) для прямого доступа к USB-устройствам из JS.
- **Sync service** — ADB-сервис передачи файлов (push/pull).
- **Shell service** — ADB-сервис выполнения команд на устройстве.
- **CNXN** — пакет рукопожатия (handshake) при подключении.
- **One-shot сессия** — shell-сессия на одну команду (OPEN → данные → CLSD).
