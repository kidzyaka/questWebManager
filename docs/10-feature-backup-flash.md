# Фичи: бэкап и ассистент прошивки

## Бэкап (селективный)

### Что входит

| Что | Как |
|-----|-----|
| Third-party APK (файлы) | `pm list packages -f` → `Sync.pull` каждого APK |
| Содержимое /sdcard (опционально) | рекурсивный pull (дерево) |
| Настройки | `settings list global/system/secure` |
| Свойства устройства | `getprop` (полный) |

**Не входит**: данные приложений (нет root), система, лицензии store-приложений
(примечание в UI: в v1 — только third-party).

### Структура архива

```
quest-backup_<model>_<serial>_<YYYYMMDD-HHmm>.zip
  manifest.json
  apks/<pkg>.apk
  sdcard/…            (зеркало, если включено)
  settings/{global,system,secure}.txt
  props.txt
```

```json
{
  "format": 1,
  "created": "2026-09-02T18:00:00Z",
  "device": { "model": "Quest 3", "serial": "…", "android": "12", "build": "…", "app": "0.1.0" },
  "packages": [ { "pkg": "com.x.y", "versionName": "1.2.3", "sizeBytes": 123, "file": "apks/com.x.y.apk" } ],
  "sdcard": { "enabled": true, "files": 1234, "bytes": 987 }
}
```

### Процедура

1. `info()` + `pm list packages -f` → список third-party (путь под /data/app).
2. (Опционально) размер /sdcard: `du -sk /sdcard` (toybox — **к проверке**)
   или обход → показываем оценку → подтверждаем.
3. Pull каждого APK → сразу в zip (fflate async). Прогресс: список файлов
   + общий %.
4. (Если включено) рекурсивный pull дерева /sdcard. Пропуск
   `/sdcard/Android/` (toggle, по умолчанию вкл). Итого > 20 GB → жёсткое
   подтверждение.
5. `settings list` × 3 + `getprop` → txt-файлы.
6. `manifest.json`, закрываем zip → скачивание в браузере.
7. Сводка: что backed up, размер, время.

### Ограничения

- Zip собирается **в памяти браузера**: /sdcard ≤ **2 GB** в v1
  (подсказка «сделайте отдельную копию по кабелю»). APK + настройки —
  обычно ок. (v2: streaming zip на диск, File System Access API.)
- Отмена в любой момент — незавершённый архив не сохраняется; на шлеме
  мусора не остаётся.

## Восстановление

1. Пользователь выбирает zip → парсим manifest → проверки: format;
   совпадение модели (не совпало — предупреждение, продолжить с
   подтверждением); пакеты vs установленные (таблица: установить /
   обновить / уже стоит).
2. (Опционально, по выбору) push зеркала /sdcard (очередь файлового
   менеджера).
3. По каждому пакету: push APK (временный каталог) → `pm install -r -d`
   → `rm`. Порядок — из manifest (best-effort для зависимостей). Непроход —
   не фатален, собираем.
4. Применение настроек (SettingsService.apply из txt).
5. (Опционально) reboot.
6. Отчёт: N ok / M failed + причины.

## Ассистент прошивки (эксперимент, M6)

### Что это и что это не это

- **Не**: автономный flash произвольного образа. Прошивка Meta подписана;
  образ мы не строим.
- **Это**: пошаговый ассистент:
  1. У пользователя есть OTA-пакет (файл) — сайт не распространяет
     прошивку, принимает только файл пользователя (примечание: доверенные
     источники).
  2. Сайт ведёт: «перезагрузите в recovery» (кнопка `reboot recovery` +
     описание комбо кнопок для модели — **к проверке**).
  3. Шлем перезагружается в recovery → переподключить USB → сайт видит
     соединение (CNXN state `recovery`).
  4. Сайт стримит пакет по протоколу **sideload** recovery (стандартный
     Android recovery поддерживает `adb sideload`).
  5. Прошивка завершается на устройстве, шлем перезагружается.

### Неизвестные (исследовать в M6)

- Точный способ входа в recovery на каждой модели (комбо кнопок).
- Поддерживает ли recovery Quest ADB/sideload по USB.
- Формат OTA-пакета Meta (`.pkg`? подписан/зашифрован) — примет ли его
  sideload.
- Протокол sideload в recovery (вариация SYNC-сервиса; сверить capture).

### UX

- Отдельная вкладка «Прошивка», за чекабоксом «Я понимаю риски».
- Чек-лист шагов (done/current/pending), без пропусков.
- Предупреждение: «Не закрывайте вкладку, не отключайте кабель, не
  выключайте шлем. Сбой прошивки может сделать шлем неработоспособным».
- Прогресс стриминга пакета (sideload показывает прогресс на шлеме).
- После завершения: «Шлем перезагрузится. Подождите».

### Статус: экспериментальный

- Не входит в Definition of Done v1. Feature flag.
- Если sideload не работает — вкладка честно показывает «не поддерживается
  на этой модели».
