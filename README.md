# Quest Web Manager

Веб-приложение для управления шлемами Meta Quest (Quest 2 / 3 / 3S / Pro)
из десктопного браузера: файлы, APK, настройки, питание, бэкап.
По USB-кабелю, через WebUSB + ADB. Без бэкенда.

## Документация

Начните с [docs/00-overview.md](docs/00-overview.md) — цели, ограничения
и полная карта документов.

## Быстрый старт (после реализации)

```
npm install
npm run dev    # http://localhost:5173 (WebUSB работает на localhost)
```

Продакшен — любой статический хостинг по HTTPS.
